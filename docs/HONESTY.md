# Honesty Protocol

## Required on every triage / valuation surface

- **Observed**: facts directly from the image or user input (marks, materials, damage, readable text, dimensions if measurable).
- **Inferred**: period, maker, authenticity probability, value range, demand signals.
- **Confidence**: explicit score or band + short reason.
- **Evidence / Sources**: links or citations when used.
- **Insufficient data**: preferred over fabricated precision.

Never present an inference as an observation. Never hide uncertainty.

This protocol is the product’s primary trust mechanism and must not be relaxed for “nicer” UX.
